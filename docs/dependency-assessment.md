# Dependency assessment

Checked 2026-10-09 using the committed npm lockfile. Expo Doctor 1.20.4 passed 21/21 checks; `expo install --check` reported compatible dependencies. `npm audit` reported 29 flagged packages: 18 high, 11 moderate, zero critical. These include dependent packages and are not 29 independent advisories. `npm audit fix --dry-run` proposed zero compatible package changes and did not modify the lockfile.

No forced framework downgrade or untested major override was applied. The audit suggests Expo 44.0.6 for several paths and Router 58.0.16 for URI decoding; these are outside the SDK 57 dependency set. Reassess a coherent supported framework upgrade before production release. Passing development checks does not resolve these findings.
