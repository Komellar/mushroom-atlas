# Mushroom Atlas

Mushroom Atlas is a mobile field reference to common mushroom species found in Poland. It brings together Polish and scientific names, photographs, and information about each species. Browse the atlas, search and filter species, or compare two species side by side. The atlas content and photographs are included with the app and available offline.

## Requirements

The project uses Node.js 22.16.0 and npm 11.4.2. You can run the web version in a browser. Android requires a device or emulator; iOS requires macOS and Xcode.

## Getting started

In the project directory, install dependencies and start the Expo development server:

```sh
npm ci
npm start
```

To start a platform directly, use the matching command:

| Platform | Command           | Requirement                |
| -------- | ----------------- | -------------------------- |
| Web      | `npm run web`     | Web browser                |
| Android  | `npm run android` | Android device or emulator |
| iOS      | `npm run ios`     | macOS and Xcode            |
